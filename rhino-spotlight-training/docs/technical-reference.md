# Technical Reference

Every technical claim used in narration or on-screen text must have a row here.

## Status key

| Status | Meaning | On-screen use |
|---|---|---|
| `GENERIC-VERIFIED` | Matches multiple manufacturer manuals / standard industry usage | OK, worded generically |
| `VARIES` | True for many fixtures, not all | OK only with a qualifier ("most", "on many models") |
| `REVIEW` | Plausible industry practice, needs qualified-instructor confirmation | Draft only until signed off |
| `UNKNOWN` | Rhino- or venue-specific; no source | Do not use |

## Excluded from the pilot (needs separate review before any lesson uses it)

- Lamp striking, ignition, and lamp changes (high-voltage ignition on arc sources)
- UV, heat, and eye-exposure hazards
- Dowser-closed duration limits (e.g., Times Square QF1000 manual reportedly advises
  turning the unit off if the dowser is down >60 s — model-specific, not generalizable)
- Fall-protection equipment and procedures
- Any Rhino-specific procedure, title, or policy

## Glossary (generic)

| Term | Plain meaning |
|---|---|
| Followspot | Lighting fixture an operator aims by hand to follow a performer |
| Dowser | Shutter or fader that blocks or dims the beam |
| Iris | Adjustable circular opening that changes beam diameter |
| Boomerang | Holder that swings color filter frames into the beam |
| Chopper / trim | Shutter blades that cut the top/bottom of the beam (Lesson 02) |
| Pick-up | Bringing the light up on a performer |
| Caller | Person calling spot cues over headset |
| Pan / tilt | Horizontal / vertical movement of the fixture |
